# Upsie

> Upsie is a direct-to-consumer warranty company offering affordable, transparent protection plans for smartphones, laptops, TVs, appliances, and other consumer electronics. For its independent repair network it publishes the Upsie Partner Network API — a JWT-authenticated REST API at api.upsie.com that lets partners create and manage repairs and subscribe to webhook events.

Generated by the API Evangelist enrichment pipeline on 2026-07-21 (method: generated — Upsie publishes no llms.txt of its own; upsie.com/llms.txt returned 404).
